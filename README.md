# Java AI Chatbot — Modern Dark GUI

A desktop educational chatbot built with Java Swing. It features a dark navy interface, purple/blue accents, a sidebar, chat bubbles, quick prompts, timestamps, and rule-based responses about Java and programming basics.

## Features
- Modern dark-themed Java Swing interface
- Chat bubbles and message history during the current session
- Quick prompts for OOP, Java features, ArrayList, study tips, and help
- Rule-based responses for Java, loops, variables, if-else, and study guidance
- Enter key and Send button support
- Works offline; no API key or external library is required

## Requirements
- JDK 8 or newer

## Run on macOS / Linux
Open Terminal in this folder and run:

```bash
javac AIChatbot.java
java AIChatbot
```

## Run on Windows
Open Command Prompt in this folder and run:

```bat
javac AIChatbot.java
java AIChatbot
```

## Important note
This is a rule-based educational chatbot, not a trained AI model and not connected to a live AI service. Its answers are based on keywords and predefined responses. Chat history is not saved after the application closes.
